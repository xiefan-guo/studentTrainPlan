# 学生培养计划管理系统 - 代码分析报告

## 一、项目概述

本项目是一个基于Flask框架的学生培养计划管理系统，主要面向高校学生，提供培养计划可视化、个性化课程推荐、课程论坛讨论以及模拟选课等功能。

**技术栈**: Python 3 + Flask + MySQL + jQuery + ECharts + NumPy

**核心功能模块**: 培养计划可视化、SVD课程推荐、课程论坛、模拟选课、学生信息管理

### 3.2 SVD推荐算法模块

#### 3.2.1 算法流程
```
┌─────────────────────────────────────────────────────────────┐
│                     SVD推荐算法流程                          │
├─────────────────────────────────────────────────────────────┤
│ 1. 构建评分矩阵 (30学生 × 118课程)                           │
│    ┌──────────────────────────────────────────┐             │
│    │ 学生\课程 │ C1 │ C2 │ C3 │ ... │ C118    │             │
│    ├──────────────────────────────────────────┤             │
│    │ S1       │ 5  │ 0  │ 3  │ ... │ 0       │             │
│    │ S2       │ 0  │ 4  │ 0  │ ... │ 5       │             │
│    │ ...      │ ...│ ...│ ...│ ... │ ...     │             │
│    └──────────────────────────────────────────┘             │
│                                                             │
│ 2. SVD分解: M = U × Σ × V^T                                 │
│    - U: 30×30 用户特征矩阵                                   │
│    - Σ: 30×118 奇异值对角矩阵                                │
│    - V: 118×118 课程特征矩阵                                 │
│                                                             │
│ 3. 降维重构 (保留90%能量)                                    │
│    k = argmin_k(Σσ_i / Σσ > 0.9)                            │
│                                                             │
│ 4. 计算预测评分                                              │
│    - 课程推荐: 基于物品相似度                                │
│    - 好友推荐: 基于用户相似度(余弦相似度)                     │
└─────────────────────────────────────────────────────────────┘
```

#### 3.2.2 核心代码分析

**SVD分解实现** ([recommed_module.py:1-144])：

```python
def recommedCoursePerson(dataMat, user, N=7, simMeas=ecludSim, estMethod=svdMethod):
    # 1. SVD分解
    U, Sigma, I_t = la.svd(dataMat)
    
    # 2. 动态确定k值(保留90%能量)
    k = 0
    while sum(Sigma[:k]) < sum(Sigma) * 0.9:
        k = k + 1
    
    # 3. 课程推荐 - 基于物品相似度
    for item in unRatedItems:
        score = estMethod([U, Sigma, I_t], dataMat, simMeas, user, item)
        item_and_score.append((item, score))
    
    # 4. 好友推荐 - 基于用户余弦相似度
    for idx, each in enumerate(userFeature):
        if user != idx:
            user_and_score.append((idx, cosSim(recomedUserVec.T, each.T)))
```

#### 5.1.2 修复方案

```python
# 使用参数化查询
def query(sql, params=None):
    db = pymysql.connect(...)
    cur = db.cursor()
    try:
        if params:
            cur.execute(sql, params)  # 参数化查询
        else:
            cur.execute(sql)
        result = cur.fetchall()
        db.commit()
    except Exception as e:
        db.rollback()
        raise e
    finally:
        cur.close()
        db.close()
    return result

# 调用方式
sql = "SELECT * FROM STUDENT WHERE STU_NO = %s"
result = query(sql, (stu_id,))  # 使用元组传递参数
```

```python
    charset='utf8'
)

def query(sql, params=None):
    db = pool.connection()  # 从连接池获取
    # ...
```
